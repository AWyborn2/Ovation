- **U7 (T7.1–T7.5).** Shared `lib/scorecard/src/kind-templates/slides.ts`: `planTemplateSlides` splits a list by the rows layer's capacity per size (even parts, junior and senior apart, cap 10 + "slides" warning) and `layoutBlocksAutomation` is the one rule for "needs a look". Server:
  - `draft-upsert` copies the kind template on insert when the switch is on (`templatedDesignFor` in `lib/kind-templates.ts`, lazily creating the template from the pack's starter); a data refresh keeps the copy and sets `layoutCheckPending`.
  - `draft-render`: templated drafts render on `blank`, one document on every slide, split by `planTemplateSlides` on every size; each `RenderedSlide` carries warnings. `checkDraftLayout` / `runPendingLayoutChecks` store per-size warnings and clear the pending flag; with no harness configured nothing runs and drafts stay pending (fail closed).
  - Gate: shared SQL `layoutClear` in `persistDueDrafts` and `autoPublishCandidates`; `effectiveDraftStatus` uses `layoutBlocksAutomation`. The scheduled sweep runs pending checks (20 per club per sweep) before promotion.
  - Publish: `prepareMedia` stores publish-time warnings for templated drafts; the worker passes `abortOnWarnings` only for `origin = 'auto'` publications.
  - Ad-hoc create copies the kind template unless the admin chose a blank canvas, a saved template or supplied a layout. PATCH of a templated draft's design sets `designEditedAt` + `layoutCheckPending`, not `editedAt`.
  - Revisions record `packId` and `templateVersion`; revert restores the design base. Migration 0035 extended (still idempotent, re-applied locally). `SocialDraft` in OpenAPI exposes `templateVersion`, `designEditedAt`, `layoutWarnings`, `layoutCheckPending`.
- **Deviation (KTD10 clarification):** the plan says both "the publish worker aborts a publication whose render warns" and "an admin can still mark the draft ready by hand". Taken literally, a card an admin cleared could never post. Resolved: only automatic publications abort; a publication an admin scheduled goes ahead, and its warnings are still stored.
- **Deviation:** layout checks run in the hourly scheduled sweep (and are bounded per club), not inline at draft creation — creation stays fast, and the pending flag keeps unchecked cards out of automation meanwhile.

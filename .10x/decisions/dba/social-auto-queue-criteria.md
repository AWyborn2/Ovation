# DBA — social-auto-queue-criteria

## Data decisions (2026-10-15)

- **No app migration.** The plan changes the shape of `social_settings.posting_plan` (jsonb) only; version 2 is validated in code and any stored plan that isn't version 2 is ignored in favour of the code default (ADR-004). `0042_posting_plan.sql` stays the latest migration. `drizzle-kit generate` reports no drift.
- **New central table `central.match_feats`** (`id` from `central.projected_line_id_seq`, `match_id`, `innings`, `club_id`, `participant_id`, `player_name`, `kind`, `detail` jsonb; index on `(match_id)`). DDL and grants live in `scripts/sql/central-projector.sql` (the projector role gets insert/delete, truncate revoked) and the Drizzle mirror in `lib/db/src/central-schema/match_feats.ts`. It is written only by the projector (`PROJECTOR_WRITABLE` guard) and rebuilt per match (delete + insert), so re-projection is idempotent. Production: re-run the projector SQL before republishing; check `to_regclass('central.match_feats')`.
- **Raw ball-by-ball volume.** `playhq.balls` now fills for every played match the sync covers (match-day, day-after, catch-up). Rough size: ~300 rows per innings, ~1,200 per two-innings match; a 60-match weekend is ~70k rows. No new index needed yet: the projector reads by `innings_id` which the loader already indexes. Revisit retention if `playhq.balls` passes a few million rows.
- **Release SQL** (`scripts/sql/auto-queue-release.sql`): two `UPDATE`s on `social_publications` / `social_drafts` filtered by `card_input->>'kind'` (no index; a one-off full scan of a small table) and one on `junior_match_display_settings` rebuilding the `team_publishing` map with `jsonb_object_agg`, guarded by `::text like '%"auto"%'` so a second run is a no-op. Tested against local Postgres (`auto-queue-release.db.test.ts`).
- **Columns left in place:** `tenants.juniors_colour` and the brand `juniorsColour` field stay (API shape unchanged); the junior surfaces no longer read them. The legacy `social_settings` automation columns stay mirrored from the plan.

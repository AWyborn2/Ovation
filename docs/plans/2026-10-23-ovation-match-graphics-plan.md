# Ovation Match Graphics in the Social Media Studio

Asked on 23 Oct 2026: bring Ash's **Ovation Match Graphics** design system (Design System
artifact `8TgcuZ3ZxL4g9HvPU6Ejqg`, version `1792725573-5e13`, synced 21 Oct 2026) into the
Studio, so every component and element in it can be used to make new designs. It ships on the
integration branch `wyborn21/social-template-library-pm` (#411) with the rest of the template
library.

## What the source holds

- Seven Match Summary looks: Broadcast, Panel, Clean, Classic, Digital Scoreboard, Ground
  Scoreboard and T20. Each renders landscape 1080×700, square 1080×1080 and portrait
  1080×1350.
- 51 layer components (the looks' parts, such as `BroadcastTitleBar` and `T20PlayerRow`) and
  `Stage`, the canvas.
- One React 18 bundle (`window.OvationMatch`) with sample data, `tokens.json` (colours, the four
  Google font families, type styles, spacing, radii, shadows, canvas sizes) and a README with
  the rules: the winner rule, readability (4.5:1), names per look, and ALL CAPS.
- Team colours are never hard-coded. Every look reads `TeamTokens` slots (`colour`,
  `onColour`, `colourOnDark`, `dark`, `bright`, `secondary`, `onSecondary`, `logo`,
  `logoOnDark`) and derives its shades from them with `shade()`.

## What the app has today (mapped 23 Oct 2026)

- **The converter** (`scripts/src/convert-pack.ts`, `scripts/src/lib/pack-convert/*`) reads a
  pack through its rendered DOM. The web app's harness mounts a card and `capture/dom.ts` walks
  it into a `PackCapture`. That holds the elements, boxes, computed styles and text runs, plus
  the colours of the palette it was drawn in. `mapCapture` turns one capture into v2 layers.
  Text showing a sentinel marker `[[key]]` becomes `{{key}}`. A colour that moves between
  sentinel palettes A and B and matches a root variable becomes `var(--token)`. Bound repeats
  become rows layers. `mergePage` then merges the sizes by layer signature.
- **The element extraction** (`scripts/src/extract-elements.ts`, D2) writes
  `lib/template-bundles/elements/<look>.json`. The API syncs it into `library_elements` at
  start, credited to the look whose slug matches the file.
- **Match Summary binds summary strings only.** The result page has `club.score` and
  `club.performers` ("Name 53 (121) · …"), but no venue, no competition, no innings in batting
  order, and no batting or bowling rows.
- **Colour tokens** are the club's (`--gold`, `--panel`, `--panel-2`, `--ink`, `--accent-ink`)
  and the Club Kit and Duotone palettes. There is no opposition or winner colour.
- **Fonts:** all four families are already in the Google Fonts catalogue the renderer loads
  from. The format has no italic (the scoreboards' type) and no font width (Archivo at 125%).
- **Sizes:** the kind's landscape is 1200×630, not 1080×700. Story has no design.

The renderer ports `shade()` exactly, so a converted shade is a token and not a frozen hex                                                                                                                                                                                                                                           | The design derives every shade from the slots. Freezing them would hard-code the sample clubs' colours                                                                                               | n/a                                                                    |

On a draw, a tie or no result, `win` is the club and `lose` the opposition, and the result line still reads the result verbatim                                                                                                                                                                                                                                                                                                                                                                                                                                                           | It's the club's own post. The fill needs a colour whatever the result                                                                                                                                | A neutral result fill on a draw                                        |

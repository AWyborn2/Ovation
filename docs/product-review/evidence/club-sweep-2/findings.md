# Club sweep 2 — data-accuracy tester panel (tenants 7–11)

**Scope.** Five central-read tenant sites, desktop 1280×720, anonymous visitor:
Pinjarra (tenant 7), South Mandurah (8), Rockingham Hornets (9), Warnbro Swans (10),
Singleton Irwinians (11). Per club: home, /players, one player detail, /matches, one match
detail (full scorecard), /grades → **B Grade** leaderboard (sweep 1 covered A Grade), /records.
Every UI number was compared against direct SQL on the `central` schema (semantics mirror
`lib/db/src/central-queries.ts`: innings excludes "did not bat", not-outs from
dismissal_type/dismissal text, games = distinct matches from batting∪roster restricted to
players with a batting line). Plus: brand checks, "Halls Head"/"HHCC" leak grep of rendered
HTML, one cross-club match opened from both sides, privacy checks against the two
`is_private=1` players that belong to this group's clubs, and console/network/broken-image
capture on every page.

**Artefacts.** Screenshots `<slug>-NN-*.png`, videos `<slug>-sweep.webm`, raw page/DOM
extraction `sweep2-extract.json`, SQL ground truth `sweep2-ground-truth.out` (generated by
`scripts/sweep2-ground-truth.sh`). Playwright driver: `scripts/sweep2-club.mjs`; the broken-logo
diagnosis probe: `scripts/sweep2-logo-probe2.mjs`.

Chosen fixtures: player = top row of each club's B Grade leaderboard; match = a recent
fully-scored B Grade match (345 Pinjarra v South Mandurah is the cross-club fixture, opened
from both sites).

---

## What works well

- **Aggregation accuracy is excellent.** Across 5 clubs × (home totals, B Grade leaderboard
  top-3, player career detail, match innings + line scores, and the single-innings records)
  every number the UI shows equals the value recomputed by independent SQL — including the
  fiddly leaderboard semantics (DNB exclusion, not-out classification from dismissal text,
  batting∪roster games union), batting/bowling averages, best-bowling tie-break (max wickets,
  min runs) and high scores.
- **Cross-club consistency is perfect** (see verdict below).
- **Tenant isolation of stats**: each site only ever shows its own club's players/matches;
  opponents appear only as opposition in match contexts.
- **Directory pagination** is honest (total = 29 with limit 20 + page 2) and private players
  are excluded from the directory and renamed on leaderboards.
- No 5xx, no JS pageerrors, no horizontal overflow seen on any of the 43 pages visited.

**Root cause of every ❌ (investigated):** the "TOTAL CLUB RECORDS" tab shows the maximum
**per (player, grade)** aggregate, not the all-time career total its header ("All-time leading
performances across all grades") promises. Verified by SQL: Rockingham's UI values 29 / 894 /
20 are exactly the per-grade maxima (Ryan Wilson A-grade games 29; Lachlan James A-grade runs
894; Cooper Clarke A-grade wickets 20), while players who split across grades (Cooper Clarke
33 games & 1219 runs & 27 wickets; Troy Morris 47 games & 1179 runs; Hunter Johnson 43 games &
872 runs) are under-counted and lose records they hold. Clubs 7/8 happen to have no multi-grade
record-holder, which is why their tab looks correct. "Most Wickets 20 Cooper Clarke" shows the
failure clearly: right holder, wrong value (20 ≠ 27). A separate "By Grade" tab already exists,
so the Total tab's per-grade behaviour is a plain bug, not a design choice. Evidence:
`rockingham-hornets-08-records.png`, `warnbro-swans-08-records.png`,
`singleton-irwinians-08-records.png`.

## Cross-club consistency verdict — ✅ PASS

Match 345 (Pinjarra 6/314 def. South Mandurah 8/188, B Grade R11 2025/26) opened from
`pinjarra…/matches/345` and `south-mandurah…/matches/345`: both sites present identical innings
totals (home/away correctly mirrored to each club's perspective) and **identical line-for-line
scorecards** — 6 batting lines and 4 bowling lines compared programmatically (dismissal text,
runs, balls, SR, overs, maidens, runs, wickets, econ): all equal. The shared formatting defects
(Issues 4/5) reproduce identically on both sides, i.e. view-model-level, not per-tenant.
Evidence: `pinjarra-05-match-detail.png`, `south-mandurah-05-match-detail.png`,
`sweep2-extract.json`.

## Issues by severity

### HIGH
1. **Private player real names leak in scorecards** (opposition lines + dismissal text) — see
   privacy verdict. Evidence: `pinjarra-09-match339-privacy-opponent-view.png`,
   `singleton-irwinians-09-match330-privacy-dismissal-text.png`.
2. **Records "Total Club Records" tab wrong for multi-grade players** — per-(player,grade)
   maxima instead of career totals; 7 of 25 checked values wrong across 3 of 5 clubs (Warnbro
   Most Games 30 shown vs 47; Rockingham Most Runs 894 vs 1219; Most Wickets 20 vs 27 same
   holder). Evidence: `*-08-records.png` + `sweep2-ground-truth.out`.
3. **Default club logo never renders**: `artifacts/cricket-club/public/ovation-logo.svg`
   contains `--` inside an XML comment ("pure shapes only -- no external font dependency") —
   illegal XML; Chromium's image decoder rejects it (verified: `new Image()` errors,
   `xml.dom.minidom` fails line 6 col 21) while HTTP returns 200. Broken-image icon in header,
   footer and scorecard innings headers on every page of 4 of 5 clubs. One-character fix.
   Evidence: any `-01-home.png`; `scripts/sweep2-logo-probe2.mjs`.

### MEDIUM
4. **Dismissal-text formatting corrupts scorecards**: caught doubled ("c c Hunter Ward b Liam
   Wilson"), stumped doubled ("st st Troy Murphy b Hunter Ward"), lbw truncated to bare "lbw"
   losing the bowler credit (DB: "lbw b Charlie Lewis"). Systemic, all clubs.
5. **Extras wrong**: "EXTRAS 0" for every innings with a wicket-prefixed score (e.g. 6/314 →
   0 shown, actual 24; the "(8W 6NB)" on the same line contradicts the 0); only all-out plain
   totals compute it (339: EXTRAS 14 = 174−160 ✅). Batting lines + extras ≠ innings total on
   9 of 10 captured innings.
6. **Home "Top Performers" permanently empty on central tenants** — "No data for this season
   yet" on all five clubs; `/api/overview/top-performers?season=2025` returns empty arrays and
   empty `availableGrades` while `/api/overview` on the same tenant returns populated
   `topRunScorers` — the panel's endpoint hasn't been repointed at central.
7. **Private-player leaderboard rows link to a dead player page** stuck on "Loading player…"
   with console 404s and no error state (`/players/24`, pinjarra).

### LOW / observations
8. All-out innings footer renders "174/0" (implies 0 wickets down).
9. Grade badges everywhere use bundled `/assets/HHCC_Icon_Gold_*.png` (Halls Head asset;
   brand-sweep inventory item).
10. Social/meta not tenant-branded: og:title "Ovation", generic description, generic favicon —
    link previews for club sites will say "Ovation" (document.title itself is correct).
11. Central premierships invisible: `central.premiers` has Pinjarra 2024/25 (A) and Warnbro
    2023/24 (B), UI shows 0 — matches curated-content design but undercuts "instantly
    populated"; seeding from `central.premiers` is on the roadmap.
12. Admin affordances visible to anonymous visitors: "Add Player" button on /players and an
    "Edit" column (→ `/stats/0`) on player detail (not clicked — club-admin tester's area).
    Evidence: `pinjarra-02-players.png`, `pinjarra-03-player-detail.png`.
13. Console noise: 401 `/api/auth/me` on every anonymous page; Google Fonts external dependency
    (blocked in sandbox → fallback fonts in screenshots; env artefact). South Mandurah's
    `logo_url` points at PlayHQ's Cloudinary — external-CDN and scraped-source branding.
14. Central seed data quality (rendered faithfully, not app bugs): impossible bowling lines
    (6-2-241-1 econ 40.17 m345; 4-1-243-0 m340), chasing side "won by N runs" (m339),
    catcher==bowler dismissals ("c Josh Taylor b Josh Taylor").

# Element library: credits and licences

The Studio's element library includes these free, openly licensed assets. The
image files live in this folder; the icons, shapes and stickers are SVG markup
in `lib/template-bundles/elements/`.

## Textures and patterns (CC BY 4.0)

Creative Commons Attribution 4.0 International
(https://creativecommons.org/licenses/by/4.0/).

- `textures-kit/`: **Textures Kit** by Bebbble
  (https://www.figma.com/community/file/1051984823754653573/textures-kit).
  Changes: exported from Figma and re-encoded as WebP.
- `seamless-patterns/`: **20 Seamless Patterns & Textures in Figma** by Simon Fairhurst
  (https://www.figma.com/community/file/1184852075345917340/20-seamless-patterns-textures-in-figma).
  Changes: each tile exported from Figma, repeated into a 1920 × 1920 sheet and
  encoded as WebP.
- `hero-patterns/`: **Hero Patterns** by Steve Schoger (https://heropatterns.com).
  Changes: each pattern drawn in black at 45% opacity, repeated into a 1920 × 1920
  sheet and encoded as PNG.

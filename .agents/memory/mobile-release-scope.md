name: Mobile release scope
description: Owner-confirmed scope and branding for the native mobile store release.
---

The owner chose “Ovation with a club-selection screen” for the first mobile
store release. Keep Ovation as the app-level branding and club branding within
the selected club's experience.

**Why:** The owner explicitly selected this rather than a Halls Head-only app
or one club per build.

**How to apply:** Plan release features, store artwork and descriptions for one
multi-club Ovation app. Do not treat the existing build-time club host as a
substitute for a user-facing club picker. Confirm implemented behavior before
claiming club selection in submitted listings.

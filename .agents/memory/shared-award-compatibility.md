---
name: Shared award compatibility
description: Why legacy edits must preserve additional recipients and names must remain independent.
---

Older award clients may only send a single player link. Treat that as an edit
to the first recipient, not permission to erase all other recipients. Only an
explicit complete recipient list replaces all links.

**Why:** Shared awards must stay safe when older mobile clients or automatic
writers coexist with the multi-recipient editor.

**How to apply:** Preserve this compatibility when changing winner writes or
imports. A display name is curated text, not a source of player identities:
never split or fuzzy-match it to infer co-winners.
